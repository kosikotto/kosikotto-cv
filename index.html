Rólam

Kosik Ottó vagyok, 23 éves mérnökinformatikus hallgató az Óbudai Egyetemen, ahol a Felhőszolgáltatási technológiák és IT-biztonság területére specializálódom.

Fejlesztői tapasztalataim közé tartoznak a Java és C# nyelvek, valamint webes technológiák, mint a HTML, CSS, JavaScript, Bootstrap, React, Tailwind CSS és TypeScript, valamint alap szinten a WordPress-hez is értek.

Jártas vagyok a Git és GitHub verziókövető rendszerek használatában, és jelenleg a Docker konténerizációs technológiát is tanulom.

Érdekel a szerverek és a felhőmegoldások világa. Tapasztalatom van AWS szolgáltatásokban (Lambda, S3, DynamoDB), valamint hagyományos szerverkörnyezetekben is, például Apache2 webszerver, Samba fájlmegosztás és Windows Server (Active Directory, fájl- és jogosultságkezelés, IIS, ütemezések).

Adatbázisok terén elsősorban MySQL-lel dolgoztam, de kis tapasztalattal rendelkezem Oracle SQL és DynamoDB használatában is.
